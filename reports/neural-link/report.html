Calibrating a language-embedding interface to a fly-derived neural circuit

Train-only input calibration, reward learning, recording-drift controls, and end-to-end reproducibility

jioh jung · jung@jioh.net
2026-09-17 · Technical research report / manuscript draft · not peer reviewed
Experiment source commit: 2d05f48a9c0d · Report version: 1.0
Simulation studyReproduction verifiedNo biological validation

Abstract

Objective. We tested whether a coordinate transform fitted only to training inputs improves semantic category retrieval and reward-trained action selection when frozen language embeddings enter a fly-derived connectivity graph. A separate module tested calibration against simulated recording drift.

Methods. Frozen FP32 EmbeddingGemma-300M features entered fixed 128-dimensional truncation, mean-centered truncation, or train-fitted rank-31 PCA. We fitted transforms/readouts with 32 training rows and selected semantic regularization on 12 validation rows. After freezing the protocol, we evaluated 64 newly authored English/Korean texts: 32 translation-paired scenarios in eight families. Semantic reconstruction and independently reward-trained native policies were assessed separately, with five port permutations, three training seeds, and a post-hoc untrained control.

Results. PCA attained 93.75% final semantic category accuracy versus 59.38% for fixed ports, and 92.19% mean native action accuracy across three seeds versus 41.15%. However, its exact within-catalog input identity retrieval was lower (10.94% versus 25.00%), and mean native probability assigned to the correct action was only 0.277. Drift calibration improved cosine under some conditions without improving classification. A fresh end-to-end run reproduced all arrays in 34 Safetensors artifacts and all final predictions exactly.

Conclusion. These findings support task-specific interface calibration in a small engineered setting. They do not establish general sentence reconstruction, biological sensory alignment, fly intention or thought decoding, or real BCI performance.

1. Introduction

Here, a “neural link” is a software interface between an embedding model and a graph-based neural simulator. The objective is to determine which input coordinates and port assignments support downstream learning, and to package that comparison as a reproducible experiment.

The fly-derived graph supplies a structural constraint for expansion and sparsification. Assigning an embedding coordinate to a particular neuron is nevertheless an engineered convention. Anatomical connectivity alone does not identify a neural code for language semantics or motivation.

QuestionTestScope of conclusion

The 64 final cases contain no fly neural recordings, sensory measurements, behavioral tracking, or biological causal interventions. Water, food, warmth, and rest are four researcher-defined action labels.

2. Biological and BCI rationale

The adult FlyWire connectome provides structural context [1]. PN-to-KC convergence has both approximately random mixing and structured sampling biases [2][3]. Port-assignment controls are therefore necessary; PCA axes are not interpreted as glomeruli or biological semantic variables.

BCI research separates the representation of changing neural recordings from a downstream decoder. Low-dimensional alignment [4] and latent-dynamics stabilization in NoMAD [5] motivate that separation. Our affine calibrator is a simpler, distinct experiment. The Neuralink platform paper [6] supplies acquisition-hardware context only.

3. Layered interface

L0

Input coordinate calibrationFixed truncation / train centering / train PCA. Persist mean and projection.
L3
PN ports → KC expansion256 signed ports + 63 padded ports → 5,177 KCs → top 104 active units.
L4a
Semantic measurement pathKC → ridge → reconstructed embedding → cosine retrieval among 40 descriptions.
L4b
Action learning pathFresh native KC→MBON readout; four actions; scalar reward.
L5
Evaluation, integrity, replayValidation-only selection → freeze → final evaluation → isolated replay.

L4a and L4b optimize different targets. The semantic probe is supervised by the original input embedding. The native policy receives rewards for sampled actions. Their accuracies are not combined into a single measure of “brain performance.”

The connectivity tables define a weighted, signed computational graph rather than physiological current units. This run uses an extracted PN→KC→MBON rate circuit, not whole-brain spiking simulation. Root identities are retained, whereas semantic coordinates, top-k sparsification, reward, and action aggregation are engineered choices.

The ordered 319 input ports, PN root IDs, KC edge counts, and coordinate/sign assignments are recorded in wiring.json. Identity order comes from the checkpoint rather than an inferred TSV sort order.

The eight final scenario families are performance, travel, home, workplace, outdoors, hobby, community, and caregiving. Each family contains an English/Korean pair for each of four classes. Cases were authored separately without consulting predictions, but are not an independently collected external benchmark. Final labels were used for evaluation, not for fitting the input transform.

“Frozen” refers to an internal configuration and file-hash lock, not registration with a preregistration registry. The untrained final control and family bootstrap added after final evaluation are identified as post-hoc analyses.

4.2 Frozen embeddings and input transforms

Original FP32 EmbeddingGemma-300M was loaded on Apple MPS with the Classification prompt, producing L2-normalized 768-dimensional vectors. No additional quantization or encoder fine-tuning was performed. The 128-dimensional truncation uses a supported MRL size [7].

x ∈ ℝ⁷⁶⁸; μ = mean(Xtrain) fixed: z = normalize(x[0:128]) centered: z = normalize(x[0:128] − μ[0:128]) PCA: Xtrain − μ = U S Vᵀ r = min(128, #{sᵢ > 10⁻⁶ s₀}, ntrain − 1) = 31 P[:, 0:r] = Vᵀ[0:r, :]ᵀ; P[:, r:128] = 0 z = normalize((x − μ) P) p[0:128] = max(z, 0); p[128:256] = max(−z, 0); p[256:319] = 0

Each principal component is sign-oriented so its largest absolute loading is positive. The stored matrix is 768×128, but only 31 directions are fitted;97 coordinates are exactly zero. All mappings obey the same319-port contract. A denominator floor of 10⁻¹² keeps an exact zero vector at zero.

4.3 Sparse activity and semantic reconstruction

h = maxnorm(topk₁₀₄(ReLU(A p))) B = row_L2_normalize(Htrain), Y = row_L2_normalize(Xtrain[:, 0:128]) C = (B Bᵀ + λ I)⁻¹ Y ê = normalize(normalize(h) Bᵀ C) ĉ = category(argmaxⱼ cosine(ê, description_embeddingⱼ))

A is the fixed PN→KC operator reconstructed from the checkpoint. Native2% sparsity retains ceil(5,177×0.02)=104 KCs, followed by per-row maximum normalization. This differs from the later L2 normalization. Ridge λ is selected from{0.01,0.1,1} by validation category accuracy, then cosine, then the smaller λ.

Exact input identity retrieval asks whether a reconstruction finds its own row among all input embeddings in the same split. It is not free-text generation; raw-embedding100% is a trivial self-comparison. Candidate-description cosine scores are not calibrated probabilities.

4.4 Independent reward learning

A fresh native engine was created for each transform and seeds 701,702,703. Each run used64 epochs, batch 8,2,048 sampled interactions, and 256 updates. Actions were sampled from the policy; a correct action received+1 and an incorrect action−1. No teacher-action update was used. Reward is computed from environment labels, so the experiment does not demonstrate autonomous discovery of the task goal.

Learning rate 0.3, logit gain 1.0, active fraction 0.02, disabled homeostasis, and opponent readout were fixed across conditions. Within a seed, epoch permutations and uniform random streams were shared, although differing policies can sample different actions. Final accuracy uses greedy argmax rather than stochastic sampling.

4.5 Controls and statistical units

For each transform, seeds 811–815 permuted the first256 signed ports. The 63 padding ports and connectivity graph were unchanged. Each permutation refit its semantic decoder on train 32 and selected λ on validation 12. All five permutations are reported; none was selected using final scores.

The 64 rows are 32 translation pairs nested within eight families. A post-hoc bootstrap resampled whole families10,000 times using seed 917. Three policy seeds and five permutations are computational repeats, not independent datasets or biological subjects. We make no p-value or population-level significance claim.

7. Recording-drift calibration

A separate study treats frozen KC activity under the original input mapping as a recording. It generates clean, gain-plus-offset,25% channel dropout, and 50% channel dropout conditions. This study uses old train 32 and validation 12 only, not the precise-interface final 64.

seed = 4401 gainⱼ = exp(N(0, 0.35²)); offsetⱼ = N(0, 0.08²) gain_offset: x′ⱼ = xⱼ · gainⱼ + offsetⱼ dropout: x′ⱼ = 0 on fixed 25% or 50% of channels; other xⱼ unchanged A = [Xobserved, 1]; D = (A Aᵀ + 0.1 I)⁻¹ Xreference Xcorrected = [Xnew_observed, 1] Aᵀ D

Balanced anchor sets contain8,16,or32 training rows, with equal counts per class. The calibrator itself receives paired activity vectors, but anchor selection uses class balance; the procedure is not entirely unsupervised. Ridge acts in the augmented space including the constant column, so the intercept is regularized. Classification uses a fixed four-class ridge probe trained on clean training activity.

The sham control shuffles correspondence between observed anchors and clean references. Access to paired clean reference activity can make this setup easier than real recording problems. Channel dropout is not treated as equivalent to functional neuron loss or changes in temporal dynamics.

NPZ loading disables pickle. Safetensors require novi.recording version 2 metadata and a seconds-based time contract. Unknown fields are rejected; paired rows are aligned by sample ID. Equal feature width is never taken as evidence for equal neuron identity.

The end-to-end software test used5,177 KC root IDs from the checkpoint as channel identities. It shuffled32 observed training rows, imported and ID-aligned them, and fitted, saved, and loaded a calibrator. Applying it to validation 12 matched direct float32 computation with zero error; reversed channel order was rejected. Timestamps are synthetic, not acquisition measurements.

8. Verification and reproducibility

Verification is distinct from model quality. A protocol lock records SHA-256 hashes for data, sources, transforms, decoders, and checkpoints. An evaluation lock links final predictions and holdout embeddings. These are integrity records for accidental changes, not a security defense against deliberate manifest rewriting.

Exact reproduction was established in the current Mac/library environment. Bitwise portability across operating systems, BLAS/MPS implementations, or library versions is untested. Because metadata ordering can change file bytes, retraining comparisons check tensor dtype, shape, and values; original locked artifacts are verified by file hashes.

9. Discussion and submission gaps

The most direct interpretation is that a low-dimensional coordinate system fitted to the data distribution better serves this sparse graph interface. PCA does not directly consume labels, but is adapted to the training-text distribution. With a small fitting set, its axes may also reflect language, sentence length, or authoring style.

Task relevance and general semantic fidelity must be separated. Higher category accuracy together with lower identity retrieval and cosine is consistent with task-favorable compression. Rank-matched random projections and larger independent data would be needed to establish that explanation causally.

The recording experiment is an important negative control. Moving closer to reference activity does not guarantee preservation of a decoder boundary. Ridge calibration distorts even clean inputs, so bypassing it under small drift may be preferable. We did not tune a new gating rule to these results.

LimitationRequired strengthening before submission

PCA-basis/graph-placement confoundingRank-matched random bases; degree-stratified permutations; other connectomes and nonbiological graphs

Supported claim: a train-only rank-31 PCA interface outperformed two MRL input baselines on a locked authored classification task, and the results reproduced exactly in the same environment. Unsupported claims: decoding fly thoughts, identifying a biological code shared by a language model and a fly, or reproducing Neuralink or NoMAD.
