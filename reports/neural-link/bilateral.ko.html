해석 경계

이 보고서의 typed site/time 경로는 모의 특징을 pooling한다. 생물학적 token, 실제 신경 기록, 사고 해독의 증거가 아니다. 실제 LM 경로는 별도 실험으로, 고정 FunctionGemma에 학습된 soft prefix를 입력한다.

두 경로를 분리해서 읽기

Typed site/time

32차원 모의 site 특징, site ID와 상대시간을 learned/fixed-query/pooled resampler가 4개 latent로 줄인다. 이것은 supervised temporal classification이다.

Actual LM soft prefix

32차원 latent 네 개를 각각 640차원으로 투영해 4×640 soft prefix를 만든다. 원본 BF16 LM은 고정되고 adapter는 FP32이다. base model fine-tuning이 아니다.

데이터와 프로토콜

  • 기존 개발: train 32 / validation 12.
  • 새 최종 세트: 저자가 작성한 64개 문장, 32개 영·한 쌍. 번역 쌍은 독립 표본이 아니다.
  • 9개 variant: 120-step 5개와 480-step long 4개. hyperparameter selection 없이 모두 평가.
  • LM 학습 seed는 하나다. 효과의 seed 안정성을 추정하지 않는다.
  • 120/480 step은 같은 seed stream을 사용한다. long 설계는 개발 결과를 본 뒤 추가되었으며 최종 selection은 없었지만 완전히 사전 독립적인 설계가 아니다.
  • label oracle 120-step은 label leakage positive control이며 480-step 모델과 동일 budget의 upper bound가 아니다.

방법 상세

Temporal 분류기는 3개 site×3개 time의 9 token을 사용한다. 실제 LM 실험은 각 예제를 current-time의 static 3 token packet으로 구성하므로 두 입력 체계를 혼동하면 안 된다.

각 site의 319/5,177/96차원 입력은 고정된 seeded projection을 거쳐 32차원 특징이 된다. resampler는 4×32 latent를 만들고, 학습된 projection이 각 32차원 latent를 640차원으로 바꿔 4×640 soft prefix를 만든다.

도구 공간은 set_goal 함수 하나와 4개 enum 값으로 닫혀 있다. open-ended tool selection 실험이 아니다.

시간 resampler

분석적 latest-only 기준선: 100.0%. 개발 temporal packet은 조건별 384개 train / 48개 validation 관측을 만든다. 100% latest-only 분석 comparator는 개발 전용이며 이에 대응하는 final comparator는 평가하지 않았다.
