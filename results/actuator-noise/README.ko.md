# 관측 횟수 잡음에 대한 실행부 보정 검사

[English](README.md) · [피드백 연구](../causal-feedback/README.ko.md)

호환되는 실행부는 네 보정용 대표 입력에서 안정적이었습니다. 목표 행동 일치율은 **총 기대 관측 횟수 32에서 99.12%, 128 이상에서 관측상 100%**였습니다. 임의의 언어 입력이나 실제 초파리 기록의 견고성을 입증한 결과는 아닙니다. 반대로 호환되지 않는 native601은 관측이 정밀해져도 잘못된 대응을 유지했습니다.

| PN 319개 전체의 기대 관측 횟수 | Native601 목표 행동 일치 | Native701 목표 행동 일치 |
|---:|---:|---:|
| 32 | 47.04% | 99.12% |
| 128 | 49.80% | 100% |
| 512 | 49.97% | 100% |
| 2,048 | 50% | 100% |
| 8,192 | 50% | 100% |

각 조건은 잡음 시드 3개·클래스당 256개, 총 3,072개의 잡음 관측을 사용합니다. 두 정책에 정확히 같은 입력을 줍니다. 전체에서 서로 다른 잡음 입력은 15,360개, 네이티브 추론 행은 30,720개이며 잡음 없는 기준 입력 8행이 추가됩니다. 기존 학습 클래스 평균 네 개를 반복해서 관측한 것이므로 독립적인 의미 사례·동물·세션·학습 시드로 해석하면 안 됩니다.

## 방법

기존 학습 클래스 평균을 고정된 SiteCodec601 PCA/PN 변환에 통과시킵니다. 음수가 없는 319차원 입력 x에 대해 포트별 기대값 `N * x_i / sum(x)`의 독립 포아송 관측을 만듭니다. N은 사전 지정한 다섯 값 중 하나입니다. 각 관측을 실제 총 횟수로 정규화하고 원래 PN 합에 맞춰, 전체 크기 변화와 횟수 변동을 분리합니다. 관측이 전부 0이면 다시 뽑지 않고 0 입력으로 남겨 기록합니다. 이번에는 그런 사례가 없었습니다.

원래 정책과 호환 정책은 실제 Rust 경로에서 배치 256으로 추론합니다. 가중치·강도·임곗값·인코더를 적합하지 않습니다. 32/128/512/2048/8192, 시드1901/1902/1903과 반복 수는 측정 전에 고정했습니다. 정수 관측 횟수, 정규화한 float32 입력, 반환된 float64 확률, 대표 입력을 `observations.safetensors`에 저장했습니다.

잡음 없는 native601 대응은 `[0,3,3,3]`, native701은 `[0,1,2,3]`입니다. 따라서 잡음을 줄이면 native601은 두 클래스에서 잘못된 행동을 더 안정적으로 실행합니다. N=32에서 native701 오류는 3,072개 중 27개로, warmth 26개·water 1개였습니다. 더 큰 네 조건의 12,288개에서는 오류가 관측되지 않았습니다. 관측 오류 0이 모집단 오류 0을 증명하지는 않습니다.

호환 정책의 잡음 없는 정답−최대 오답 확률 차이는 0.01950~0.03799입니다. 클래스별 정답·원래 행동과의 일치율, 확률 차이의 최소·5%·중앙·95%·최대값은 [원시 보고서](report.json)에 있습니다. 보정된 생물학적 확신이나 실행부 안전 보장은 아닙니다.

## 재현

```sh
.venv/bin/python examples/bio_bridge/actuator_noise.py verify
```

저장한 텐서 80개와 보고서 수치 전체가 정확히 재생됐습니다. [검증 기록](verification.json). 소스 lock은 코드·모델·NumPy·Python과 함께 당시 설치된 native 공유 라이브러리의 해시도 고정합니다. 엄격한 재실행에는 그 바이너리 식별값이 필요하며, 이식용 소스 번들에서는 플랫폼 바이너리를 제외합니다. 새로 빌드한 wheel은 계산이 같더라도 파일 해시가 다를 수 있습니다. 이 잡음 실험의 엄격한 재현과 언어 모델 피드백의 경로 이전 재현은 구분해야 합니다.

포아송 관측은 추상적 모형입니다. 횟수를 밀리초·실제 초파리 발화율·생물학적 관측 창·전극 통계로 환산하지 않았습니다. 상관 잡음, 드리프트, 채널 누락, 인코딩 변경, 새로운 입력과 행동 대표 신호는 시험하지 않았습니다. 범용 관측량이나 성능 최적점을 정할 근거가 아닙니다.
