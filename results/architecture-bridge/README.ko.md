## 실험과 주장 범위

- 학습32개, 재사용 개발 평가12개, 새 일반64문장과 적대적64문장. 각64문장은32개 한영 번역 쌍·8개 상황군이다. 외부 벤치마크나 실제 신경 관측 자료가 아니다.
- PCA 유효 rank31, 고정 PN→KC 연결과2% 경쟁을 사용했다. 이번 문맥·위치 평가는 지도 프로브이며 native 보상 학습이 아니다.
- 4가지 문맥 규칙과 대체 규칙표, 문맥 교란·누락·오래된 latch·초기화, 채널 순열·KC 가지 제거를 비교했다. 외부 latch 일치는 학습된 기억의 증거가 아니다.
- 위치별 출력 계수132개를 맞췄지만 정보량·유효 rank는 같지 않다. MBON은 이전에 학습한 checkpoint이며 다중 위치에는 PN/raw 경로가 있다.
- Landmark는 고정 무작위 그룹 합산이다. 학습 토큰, attention, 실제 해부학적 위치 의미를 구현한 결과가 아니다.
- mHC 검사는 이중 확률 혼합의 대수적 반례다. 균등 혼합은 안정적이어도 rank1로 정보가 소실된다. 실제 mHC 학습 결과가 아니다.

## 다음 구조 제안

먼저 위치·시간·채널 마스크·정규화·문맥 가용성을 명시하는 인터페이스를 만들고, 작은 학습 query resampler를 고정 query와 동일 규모 MLP에 비교하는 편이 타당하다. 의미 보존 경로와 행동 경로는 따로 제거해 검증할 수 있어야 한다. 문맥 기억은 직접 임베딩 재귀 모델 및 해석 가능한 외부 상태 기준선과 비교해야 한다.

큰 LoRA/full 모델의 효용을 검증하려면4분류를 넘어서는 의미 복원·신경 동역학 예측 같은 목적과 훨씬 많은 독립 학습군이 필요하다. 본체 미세조정은 별도 외부 평가와 언어 능력 망각·Mac 메모리·처리량 검증을 갖춘 후속 실험으로 분리했다. 현재 엔진 기본값은 바꾸지 않았다.

## 재현

프로토콜·코드·데이터·가중치·모델 revision과 행 ID를 해시로 잠갔다. 두 최종 세트는 저장된 가중치만 불러와 정확히 재실행됐고, bio-bridge 테스트83개(새 테스트16개)가 통과했다. MPS 재학습의 비트 단위 동일성이나 생물학적 재현을 의미하지 않는다. 로컬에서 접근 가능한 파일이므로 암호학적 블라인드 평가를 주장하지 않는다.

```bash
.venv/bin/python examples/bio_bridge/architecture_study.py verify
.venv/bin/python -m unittest discover -s examples/bio_bridge -p 'test_architecture*.py' -q
.venv/bin/python reports/neural-link/build_architecture_report.py
```

Safetensors는 기존 정책에 따라 로컬 생성물이며 Git에는 포함하지 않았다. 정확한 재실행에는 해당 파일이 필요하고 JSON만으로는 충분하지 않다. 새 실행은 격리된 출력 위치에서 `develop → freeze → encode → final → verify` 순서로 진행한다. 상세 준비 조건과 제약은 영문 문서에 기록했다.
