# 임베딩–회로–언어 모델 양방향 인터페이스 연구

[English](README.md) · [상세 HTML 보고서](../../reports/neural-link/bilateral.ko.html) · [논문 근거](../../examples/bio_bridge/BILATERAL_RESEARCH.ko.md)

고정된 원본 BF16 FunctionGemma-270M에 회로 특징을 연속 soft prefix로 넣어 실제 함수 호출을 생성했습니다. 다만 **초파리 사고 해독, 범용 뇌 인터페이스, 구조적 비약을 입증한 결과는 아닙니다.** 새로 작성한 적대적 문장 64개에서 단순 풀링이 35개, 학습 쿼리가 32개, 고정 쿼리가 33개를 맞혔습니다. 최종 결과에 따라 모델을 골라 재학습하지 않았으며 실패를 포함한 모든 조건을 보존했습니다.

## 연결 구조와 실험 구분

입력은 고정 EmbeddingGemma-300M의 768차원 분류 임베딩입니다. 회로 경로는 기존 학습 32개로만 맞춘 PCA 변환을 거쳐 PN 319개, KC 5,177개 중 활성 104개, MBON 96개의 특징을 읽습니다. 고정 난수 투영으로 위치별 특징을 32차원으로 줄입니다. 직접 임베딩 비교군은 회로 없이 세 개의 768→32 고정 투영을 사용합니다. 이후 어댑터 크기는 같지만 상류 전체 용량은 일치하지 않으며 MBON 가중치에는 기존 학습 데이터의 지도 정보가 들어 있습니다.

- **시간 결합 실험:** −2, −1, 0 시점의 관측마다 세 위치를 읽어 총 9개 토큰을 만듭니다. 네 개의 32차원 잠재 벡터와 분류기가 가장 최근 관측의 클래스를 예측합니다. 과거 관측은 기존 학습 데이터에서 현재 정답과 무관하게 뽑습니다. 외부에서 지정한 시간으로 최신 프레임을 선택하는 과제이며 생물학적 순환 기억이 아닙니다. 학습 쿼리·고정 쿼리·풀링을 각각 3개 시드로 비교했습니다. 고정 쿼리도 attention과 위치·시간 변환은 학습합니다. Adam 0.003, 배치 32, 300회 갱신을 사용했습니다. 학습 384개와 개발 48개 에피소드는 각각 원문 32개·12개에서 파생되어 서로 독립이 아닙니다.
- **실제 언어 모델 실험:** 현재 시점의 세 위치 토큰만 사용합니다. 시간 실험의 9개 토큰과 구분해야 합니다. 네 개의 32차원 잠재 벡터를 각각 640차원으로 투영해 고정된 112토큰 프롬프트 앞에 붙입니다. FP32 어댑터만 학습하고 BF16 본체는 고정합니다. 도구는 `set_goal` 하나이며 인자는 water/food/warmth/rest 중 하나입니다. 실제 자기회귀 생성을 사용하지만 자유로운 도구 탐색이나 언어 재구성은 아닙니다. 주 지표는 파싱 가능한 정답 함수 호출입니다. 네 후보의 합산 로그우도 순위는 보조 지표이며 warmth가 16토큰, 나머지가 15토큰이어서 길이 편향이 가능합니다.

언어 모델 어댑터는 시드 1701, AdamW 0.003, 배치 4, 가중치 감쇠 0, 기울기 제한 1을 사용했습니다. 학습/고정/풀링의 학습 파라미터 수는 각각 25,728/25,600/25,787개입니다. 초기 120회 조건 다섯 개와 480회 조건 네 개를 비교했습니다. 480회 조건은 개발 결과를 본 뒤 최종 동결 전에 추가했습니다. 같은 난수 스트림 앞부분을 공유하므로 독립 반복 실험이 아닙니다. 정답을 직접 주입하는 120회 oracle은 누수를 의도한 양성 대조군이며 배포 방법이나 480회 조건과 같은 예산의 상한이 아닙니다.

## 새 64개 문장 평가

| 입력 / 어댑터 | 학습 횟수 | 정답 / 64 | 유효 호출 / 64 | 입력 섞기 정답 / 64 |
|---|---:|---:|---:|---:|
| 회로 / 학습 쿼리 | 120 | 15 | 45 | 12 |
| 회로 / 고정 쿼리 | 120 | 31 | 64 | 23 |
| 회로 / 풀링 | 120 | 29 | 64 | 24 |
| 직접 임베딩 / 학습 쿼리 | 120 | 14 | 64 | 16 |
| 정답 주입 대조군 | 120 | 64 | 64 | 20 |
| 회로 / 학습 쿼리 | 480 | 32 | 63 | 20 |
| 회로 / 고정 쿼리 | 480 | 33 | 64 | 20 |
| 회로 / 풀링 | 480 | 35 | 64 | 22 |
| 직접 임베딩 / 학습 쿼리 | 480 | 19 | 64 | 18 |

영벡터 prefix는 모든 조건에서 유효 호출이 0개였습니다. 반면 기존 학습 입력의 prefix 평균은 일정한 유효 목표를 출력해 모든 조건에서 16/64를 맞혔습니다. 따라서 영벡터에서 실패했다는 사실만으로 의미 전달을 입증할 수 없습니다. 함수 호출 형식을 유지하는 학습 신호까지 제거하기 때문입니다. 입력 섞기는 64개 중 20개에서 같은 클래스를 보존하며, 같은 행이 그대로인 경우는 0개입니다. 완전한 의미 제거 대조군은 아닙니다. 동일 prefix 생성은 캐시를 사용하므로 논리적 평가 행과 독립적인 물리적 생성 횟수도 구분합니다.

평가 문장은 8개 상황 계열, 32개 영·한 번역 쌍으로 구성했습니다. 다른 사람의 요구, 과거 상태, 인용문, 가정을 섞었습니다. 외부 벤치마크나 암호학적으로 가려진 평가가 아닙니다. 특히 480회 고정 쿼리는 기존 개발 세트에서 12/12였지만 새 세트에서는 33/64에 그쳤습니다. 개발 성능을 견고한 의미 전달로 일반화할 수 없다는 반례입니다.

사후 분석에서는 32개 번역 쌍을 단위로 10,000회 부트스트랩했습니다. 480회 학습 쿼리에서 고정 쿼리를 뺀 차이는 −1.56%p, 95% 구간 [−18.75, 14.06]입니다. 풀링 대비 차이는 −4.69%p [−17.19, 7.81], 직접 임베딩 대비 차이는 +20.31%p [6.25, 34.38]입니다. 작성된 문장과 해당 재표집 방법에 대한 구간이며 학습 시드 안정성이나 커넥톰의 인과적 효과를 뜻하지 않습니다. 8개 상황 계열을 단위로 한 분석도 별도로 남겼지만 군집 수가 작습니다. 다중 비교를 보정한 우월성 주장은 하지 않습니다. [원시 분석](posthoc-analysis.json).

120→480회로 늘렸을 때 개선/악화한 문장은 학습 쿼리 23/6개, 고정 쿼리 18/16개, 풀링 17/11개, 직접 임베딩 19/14개입니다. 평균 향상이 모든 사례의 향상을 의미하지 않습니다.

## 시간 실험

3개 학습 시드와 문장당 과거 문맥 4개의 최종 정확도 평균입니다.

| 입력 | 학습 쿼리 | 고정 쿼리 | 풀링 |
|---|---:|---:|---:|
| 회로 | 52.47% | 57.81% | 33.33% |
| 임베딩 | 47.92% | 43.88% | 29.43% |

에피소드는 독립 표본이 아닙니다. 최신 프레임만 선택하는 단순 ridge 기준선의 기존 개발 정확도는 100%였지만 사전 선언된 최종 비교군으로 평가하지 않았습니다. 그 개발 수치를 위 최종 수치와 직접 비교하면 안 됩니다. 시간 뒤집기, 현재 프레임 제거·영벡터화, 행 섞기, 메타데이터만 남기기의 시드별 결과는 [원시 결과](temporal-final.json)에 있습니다. 시간 뒤집기는 이미 학습에 쓰인 과거 관측을 정답으로 만들 수 있으므로 그 성공이 새로운 의미 일반화를 뜻하지 않습니다.

## 두 번 판단하는 연결과 정책 호환성

사전 지정한 8개 사례는 각각 독립적으로 초기화했습니다. 첫 함수 호출의 목표를 파싱하면 그 클래스의 기존 학습 임베딩 평균을 선택하고, 이를 회로 특징으로 바꿔 두 번째 입력으로 사용합니다. 파싱 실패는 쓰기를 거부합니다. **네이티브 회로의 행동 출력은 기록만 하고 다음 언어 모델 입력에 사용하지 않습니다.** 실제 경로는 `언어 모델 목표 → 호스트의 대표 예시 → 위치 특징 → 언어 모델 목표`이며 환경·행동 피드백이나 학습된 순환 구조가 아닙니다.

정책 601에서 고정 쿼리의 목표는 8/8 유지됐지만 5개는 틀린 답의 고정점이었습니다. 학습 쿼리도 8/8 유지됐지만 2개가 틀렸습니다. 교정된 사례는 둘 다 0개였습니다. 네이티브 행동과 생성된 목표의 일치는 각각 1/8, 3/8에 그쳤습니다.

동일 그래프와 순서가 같은 포트·가소성 슬롯을 검증한 뒤 가소성 가중치를 정책 701로 바꿨습니다. 어댑터는 그대로지만 MBON 특징과 네이티브 행동 정책이 함께 변합니다. 행동과 생성된 목표는 두 어댑터 모두 8/8 일치했습니다. 그러나 고정 쿼리의 언어 정답은 3/8 그대로였고, 학습 쿼리는 6/8에서 4/8로 하락했습니다. 명령 실행의 개선이 의도 해석의 개선을 보장하지 않습니다. 행동 피드백의 인과적 효과를 분리한 실험으로 해석하면 안 됩니다. 네이티브와 shadow 확률의 최대 차이는 1.49e-8로 허용치 2e-6 안이었습니다. 8개 사례는 기술적 점검이며 대표성 있는 폐루프 벤치마크가 아닙니다.

## 저장·동결·재현

최종 임베딩 계산 전에 `protocol-lock.json`으로 수치 코드, 입력, 모든 어댑터·codec·분류기, 두 네이티브 정책, 최종 문장, 모델·설정·토크나이저 해시를 고정했습니다. `final-started.json`은 최종 평가의 묵시적 재실행을 막고 `evaluation-lock.json`은 결과를 고정합니다. 가중치는 Safetensors로 저장했습니다. 480회 모델 네 개는 학습 전후 본체 전체 메모리 해시 일치와 본체 기울기 부재를 확인했습니다. 초기 120회 모델은 이보다 약한 고정 파라미터·디스크 파일 증거만 있으며 당시 코드를 별도로 보존했습니다.

```sh
.venv/bin/python examples/bio_bridge/bilateral_study.py verify
.venv/bin/python -m unittest discover -s examples/bio_bridge -p 'test_*.py' -q
.venv/bin/python reports/neural-link/build_bilateral_report.py
```

저장 가중치를 다시 로딩해 시간 실험 전체, 언어 모델 9종·조건 4개의 64행 후보 우도와 순위, 조건마다 사전 지정한 8행의 실제 생성(모델당 논리적 32행), 정책 교체 전후의 두 번 판단 전체를 재검증했습니다. 후보 우도 오차는 모든 모델에서 0, 지정 생성과 순위는 모두 일치했습니다. 시간 측정은 비교에서 제외하며 학습의 비트 단위 재현이나 64행 전체 생성의 재실행을 주장하지 않습니다. BF16은 배치 모양에 따라 우도가 달라질 수 있어 같은 배치 크기를 사용합니다.

언어 모델 경로는 Torch MPS, 작은 시간 모델은 CPU를 사용했습니다. 이번 결과는 MLX-C 속도 비교나 30 TPS 서빙 검증이 아닙니다. JSON만으로는 재실행할 수 없으며 동일 Safetensors와 원본 Gemma 파일이 필요합니다. 재현 번들·경로 이전 실행기는 원본 콘텐츠 해시를 유지해야 합니다. 네이티브 바인딩은 `.venv/bin/python -m pip install -e .`, 의존성은 `requirements-functiongemma.txt`로 설치합니다. 새 학습 실험은 별도 체크아웃·출력 위치에서 수행하고 발표된 lock을 삭제해서 재사용하지 마세요.

## 생물학적 근거와 다음 반증 실험

현재 신호는 소프트웨어에서 만든 발화율 특징이며 실제 초파리 신경 기록이 아닙니다. 공개 ORN의 스파이크·칼슘 데이터 가져오기를 실제 시도했으나 워크북 다운로드가 403/401로 막혔습니다. 짝지어진 관측 0개, 실제 생물 데이터에 대한 적합 결과 0개입니다. [가져오기 기록](../orn-data-pilot/import-report.json), [데이터 연구](../../examples/bio_bridge/PAIRED_DATA_RESEARCH.ko.md).

다음 검증은 동물·세션을 분리한 실제 신경–행동 데이터, 쓰기 없음·행동 섞기 대조군을 둔 행동→환경 관측 피드백, 감독 정보와 그래프 통계가 일치하는 무작위 토폴로지, 입력 크기를 맞춘 위치 제거, 새로운 문장 계열에서의 여러 학습 시드입니다. 현재 결과는 쿼리 수나 어댑터 크기를 먼저 늘리기보다 전달 경로와 보정을 검증해야 한다는 근거입니다. 생물학적 인지나 인간 전두엽에 대응하는 기관, 마음 읽기를 입증하지 않습니다.

## 경로를 바꿔 재실행하기

날짜를 붙인 [재현 압축 파일](https://github.com/ziozzang/novigrad/releases/download/v0.1.1/novigrad-bilateral-20260917.tar.gz)을 기존 v0.1.1 릴리즈에 연구 부록으로 첨부합니다. 릴리즈 태그는 이동하지 않습니다. 작은 Safetensors, 동결 코드, 네이티브 빌드 소스, 결과 lock을 포함하며 Gemma 본체 가중치와 미리 빌드한 네이티브 바이너리는 제외합니다. [체크섬](https://github.com/ziozzang/novigrad/releases/download/v0.1.1/novigrad-bilateral-20260917.sha256). 압축 해제기는 전체 목록·해시를 검증한 뒤 새 디렉터리에 기록합니다. 경로 이전 실행기는 원본 모델 콘텐츠를 유지하면서 경로 조회만 바꿉니다.

```sh
.venv/bin/python scripts/package_bilateral.py unpack \
  /path/to/novigrad-bilateral-20260917.tar.gz /new/replay-directory
cd /new/replay-directory
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-functiongemma.txt scipy==1.17.1
.venv/bin/python -m pip install .
.venv/bin/python examples/bio_bridge/replay_bilateral.py \
  --embedding-model /local/google_embeddinggemma-300m \
  --function-model /local/google_functiongemma-270m-it
```
