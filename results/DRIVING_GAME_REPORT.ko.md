# 폐루프 주행 게임: 보상으로 단순한 생존 행동 배우기

기존 Novigrad 엔진을 HighwayEnv 게임에 연결해 정답 행동 없이 학습했습니다. 시험 게임20개에서 충돌은 **초기 모델15/20 → 학습 모델1/20**, 평균 점수는 **22.20 → 27.95**로 개선됐습니다. 다만 주로 감속·유지를 배웠고, 항상 감속하는 규칙은 충돌0/20·점수28.67로 더 좋았습니다. 따라서 복잡한 교통 판단이나 임의 게임의 목적 이해를 입증한 결과는 아닙니다.

| 정책 | 평균 점수 | 충돌 | 평균 진행 거리 | 평균 속도 |
|---|---:|---:|---:|---:|
| 검증으로 선택한 학습 모델 | 27.95 | 1/20 | 394.41m | 20.48m/s |
| 초기 모델 동결 | 22.20 | 15/20 | 331.64m | 24.80m/s |
| 무관한 보상 학습 | 22.20 | 15/20 | 331.64m | 24.80m/s |
| 무작위 행동 | 16.92 | 15/20 | 253.44m | 24.91m/s |
| 항상 유지 | 22.20 | 15/20 | 331.64m | 24.80m/s |
| 항상 감속, 사후 진단 | 28.67 | 0/20 | 403.00m | 20.08m/s |

학습 정책은 시험의773번 결정에서 유지575번·감속198번을 선택했습니다. 차선 변경과 가속은 선택하지 않았습니다. 초기 모델은 계속 유지 명령을 선택했습니다. 게임의 최소 목표 속도가20m/s이므로 감속을 반복해도 정지하지 않습니다. 배운 것은 이 단순한 환경에서 점수를 보존하는 보수적인 속도 정책입니다.

항상 감속 기준선은 학습 행동 빈도를 확인한 뒤 추가한 진단입니다. 이 결과로 모델이나 설정을 바꾸지는 않았으며, 재현 스크립트에는 앞으로 기본 기준선으로 포함됩니다. [전체 시험 기록](driving-game/summary.json), [감속 기준선](driving-game/posthoc_slow_baseline.json), [게임 GIF](driving-game/driving.gif)를 남겼습니다.

## 초기화와 시험 방식

학습률0.01과0.05는 각각 새 엔진으로 시작합니다. 초기 Safetensors 텐서14개는 가중치·출력 gain을 포함해 모두 동일함을 확인했습니다. 설정 메타데이터의 학습률만 다릅니다. 무관한 보상 대조군 역시 선택된 설정의 **초기** 체크포인트에서 시작합니다. 앞선 실험의 학습 결과를 이어받지 않습니다.

에피소드마다 도로·차량을 초기화하되, 같은 학습 실행 안에서는 가중치를 유지합니다.4에피소드 동안 고정된 가중치로 관측·행동·보상을 수집한 뒤 평균 기울기로 한 번 갱신합니다. 현재 엔진은 feedforward이므로 에피소드 간 유지되는 재귀 hidden state는 없습니다.

학습 seed는1000–1127, 검증은10000–10007, 시험은20000–20019로 분리했습니다. 초기 및32·64·96·128에피소드 체크포인트를 검증 점수로 비교한 결과 학습률0.01·96에피소드 모델이 선택됐습니다. **검증과 시험에서는 학습하지 않습니다.** 동일하게 동결한 모델을 시험20개에 적용합니다.

오래 학습한다고 계속 좋아지지는 않았습니다. 학습률0.01의 검증 충돌률은96에피소드에서0%였지만128에피소드에는75%로 다시 나빠졌습니다. 최종 가중치 대신 검증 기준으로 선택한 체크포인트를 사용했습니다. 학습 RNG는 한 seed이며 검증8게임·시험20게임의 작은 실험이므로 독립 학습 반복에 대한 안정성은 아직 측정하지 않았습니다. [초기 텐서 비교와 해시](driving-game/verification.json)를 포함했습니다.

## 학습 메커니즘

HighwayEnv1.12.1의 `highway-fast-v0`를 사용했습니다.3차선·주변 차량12대·제어 차량1대·20초 게임이며 행동 결정은2Hz, 물리 계산은10Hz입니다. 빠른 변형은 주변 차량끼리의 충돌 검사를 생략합니다. 관측은 자신과 주변 차량의 존재·위치·속도5×5 수치입니다. 영상보다 직접적인 정보이며, 원시 카메라에서 물체 상태를 추정하는 과정은 없습니다. 저수준 조향·속도 제어도 시뮬레이터가 맡습니다.

관측을 양·음 두 채널로 나눠319개 입력률로 매핑합니다. 보상·충돌 여부·정답 행동을 입력 인코더에 넣지 않습니다. 모델의 출력 확률에서 행동을 뽑고 환경을 진행시켜 스스로 결과를 경험합니다.

할인율0.97로 앞으로 받은 보상을 합산하고, 이전 배치에서 유지한 시간별 보상 기준값을 뺍니다. 이 값을10으로 나누고[-1,1]로 제한해 해당 행동의 보상 기울기로 사용합니다.4에피소드의 평균 기울기는 기존 HTTP `/learn`과 Rust 엔진을 통해 반영합니다. 기준값은 갱신 뒤 계수0.1로 이동 평균을 냅니다. 종료 뒤 보상은0으로 채웁니다. 보상이 행동에 미치는 영향을 추정하는 REINFORCE 계열의 공학적 구현입니다.

이 실험의 여러 단계 보상 계산은 Python 러너에 있으며, 별도의 Rust `DelayedReward` 래퍼를 호출하지는 않습니다. 같은 보상 기울기 핵심을 재사용하지만 실제 도파민 회로를 재현한다는 뜻은 아닙니다. 대조군은 배치 안에서 보상 신호를 섞어 관측·행동과의 관계를 깨뜨립니다. 작은 실험에서 우연한 상관이 남을 수 있습니다.

## 목적을 알아낸다는 의미와 한계

게임의 점수 규칙은 환경에 정의돼 있습니다. 도로 위에서 정규화된 보상은 `(1 − 충돌 +0.4×속도점수)/1.4`이며 속도점수는20–30m/s 구간을0–1로 바꾼 값입니다. 느리게 달려도 충돌하지 않으면 매 단계 약0.714를 받고, 충돌하면 게임이 끝납니다. 따라서 감속해 오래 생존하는 것이 유리합니다.

모델은 이 점수를 높이는 행동을 탐색으로 발견했습니다. 점수가 전혀 없는 게임의 의미·목적을 스스로 이해하거나 유용한 목적을 발명한 것은 아닙니다. 앞으로 더 어려운 게임을 만들려면 항상 감속·유지하는 규칙만으로는 충분하지 않도록 구성하고 진행 거리·속도·충돌을 함께 평가해야 합니다. 호기심·새로움 보상을 추가하더라도 그 기준 자체는 설계한 목적입니다.

## 실행 성능과 재현

세 학습 실행은 M2 Ultra에서 각각26.80·29.75·26.92초였습니다. 중간 검증은 포함하고 설치·빌드·최종 시험은 제외합니다. 첫 시험 seed의 별도40회 재생에서 관측 인코딩·HTTP 추론·시뮬레이터 진행은 평균11.65ms, 최대13.19ms였습니다. 이 게임의 정책 주기는500ms입니다. 실제 카메라·액추에이터나 hard real-time 검증은 아닙니다.

모델은 로컬 `results/driving-game/model.safetensors`에 저장됩니다. 재현 시 연결망과 보상만으로 다시 만들 수 있습니다. GIF40프레임을 생성해 확인했으며 SDL dummy 드라이버에서 검게 그려지는 문제를 수정해 다시 렌더했습니다. 학습·시험 결과에는 변화가 없습니다.

Rust35개·Python12개 테스트, Clippy, 포맷 검사를 통과했습니다. 새 `novi_engine init`은 모델 설정·출력 gain·재로딩·기존 파일 덮어쓰기 방지를 검사합니다. [게임 실행 예제](../examples/driving-game/README.ko.md)와 [영문 상세 보고서](DRIVING_GAME_REPORT.md)를 참고하세요.
