# 이미지 검증 — v0.1.0

[English: 전체 seed별 수치와 프로토콜](VISION_REPORT.md)

실제 Rust 연결망 엔진을 지도 학습한 뒤, 별도 시험 세트로 평가했다. 세 학습 seed의 평균은 다음과 같다.

| 과제 | 시험 성능 |
|---|---:|
| Fashion-MNIST 의류 10종 | 72.62% (72.45–72.80%) |
| 합성 CAPTCHA 문자 | 83.32% (83.05–83.55%) |
| 네 자리 모두 정답 | 48.67% |

Fashion은 학습/검증/시험 10,000/2,000/2,000장, CAPTCHA는 3,000/500/500개의 전체 이미지다. 시험 문자열은 다른 분할과 중복되지 않으며, 두 데이터셋 모두 학습·시험 간 동일 이미지 중복은 0이다. CAPTCHA의 글꼴과 잡음 분포는 분할 사이에 공유한다.

어댑터는 학습 이미지에서만 비지도 PCA를 맞추며 사전 학습 CNN·OCR을 사용하지 않는다. 기존 FlyWire 시냅스 62,261개 중 62,260–62,261개 가중치가 변했다. 고정 가중치 및 라벨 섞기 대조군은 약 10% 수준이며, 회로가 입력과 라벨의 관계를 실제로 학습함을 지지한다. 확률 자체는 아직 낮고 보정된 신뢰도로 해석할 수 없다.

하이퍼파라미터와 seed를 고정한 뒤 시험 세트를 평가했다. 검증 세트로 epoch를 고르고, 배포 모델은 시험 결과와 무관하게 seed 1을 사용한다. 세 seed는 동일 데이터 분할을 사용하므로 데이터셋 간 일반화의 오차 범위를 뜻하지 않는다.

의류 분류는 일반 장면 탐지가 아니며, CAPTCHA는 위치가 고정된 네 셀과 생성기의 글꼴·잡음 분포 안에서만 검증했다. 임의의 웹 CAPTCHA 해결을 주장하지 않는다. 이미지 학습은 지도 방식이고, 스칼라 보상 학습은 별도 합성 과제에서 검증했다.
