# Gemma → novi 연결 실험

원본 FP32 EmbeddingGemma 300M을 Mac MPS에서 실행하고, 고정된 의미 벡터를 novi의 319개 입력 포트에 연결했습니다. 네 가지 필요(물·음식·보온·휴식)에 맞는 행동을 실제 보상으로 학습합니다. 이는 작은 contextual bandit이며 완성된 주행 게임이나 실제 뇌 인터페이스는 아닙니다.

3개 seed 평균: novi는 새로운 영어 문장 **84.72%**, 한국어 **83.33%**입니다. 같은 입력의 선형 정책은 영어 **83.33%**, 한국어 **86.11%**였습니다. 보상을 섞으면 두 정책 모두 25%였습니다. 전체 768차원 최근접 예문 기준선은 두 시험에서 91.67%이므로 novi가 의미 표현 자체를 개선했다고 말할 수 없습니다. 표본이 작아 우월성을 주장하지 않습니다.

각 실행은 기존 학습 모델을 불러오지 않고 연결 파일에서 새 정책을 만듭니다. Gemma는 학습하지 않습니다. 보상 규칙을 뒤집는 단계에서는 같은 정책을 이어서 학습합니다. 기본 설정은 이 재학습에 실패했습니다(novi 25%). 탐색·엔트로피·낮은 출력 gain 후속 실험도 원본 결과와 분리해 남겼으며, 재사용한 시험 문장이므로 탐색적 결과입니다.

3개 정책 모두 Safetensors 저장·복원 뒤 80개 입력의 확률이 정확히 일치했습니다. 별도 한국어 문장으로 실제 모델과 저장된 정책을 실행하여 물 행동을 선택하는 것도 확인했습니다.

실행 명령과 데이터 준비: [영문 사용법](README.md). 상세 수치·혼동행렬·학습률 선택: [원본 결과](../../results/gemma-bridge/experiment.json).

연결 위치는 [신경과학 검토](RESEARCH.ko.md)를 참고하세요. 현재 의미 벡터→ALPN 포트는 공학적 연결입니다. FC2·EPG·PFL 뉴런은 후보 ID와 연결을 확인한 단계이며 아직 그 동역학을 구현하거나 의미 벡터를 주입하지 않았습니다.

후속 실험에서 gain 1, 엔트로피 계수 0.5, 단계별 16,384회 상호작용을 사용하면, 같은 novi 가중치를 이어서 학습하여 규칙 변경 후 영어 정확도 83.33~87.50%로 회복했습니다. 학습량과 설정이 함께 바뀌었으므로 단일 요인의 효과나 선형 정책보다 우수하다는 결론은 내릴 수 없습니다. 원본과 후속 실험은 별도 JSON으로 보존했습니다. 저장된 모델 번들은 원본 실험의 규칙 변경 전 모델입니다.
