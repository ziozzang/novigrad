# Fly-inspired learning constraints for the bio bridge

## Scope and interpretation

This document proposes experiments; it reports no new runs. The biological sources are primary studies, but the software mechanisms below are hypotheses inspired by those studies, not implementations of fly neurons.

There is no basis here for calling either interface a fly prefrontal cortex homologue. A frozen EmbeddingGemma vector is an engineered representation of language, not an odor code, projection-neuron pattern, or Kenyon-cell (KC) population. FunctionGemma emits executive symbols through a typed interface; those symbols are not mushroom-body output. A host-side queue linking an action to later feedback is bookkeeping, not an actual synaptic eligibility trace.

The useful separation is architectural. EmbeddingGemma supplies fixed sensory features. A small plastic layer can learn values or actions from those features. FunctionGemma can parse an explicit request and propose a typed operation. The environment must own hidden state, validate schemas and ordering before mutation, execute actions, and generate physically grounded outcomes.

## What the experiments establish—and what they do not

| Primary study | Direct result and causal limit | Software hypothesis and falsifiable test |
|---|---|---|
| [Lin et al., 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4000970/) | Acute APL output blockade broadened and correlated KC odor responses and selectively impaired learned discrimination of similar odor pairs. The authors explicitly note that the manipulation does not prove sparseness itself is the mediator. | Add a deterministic top-k/competitive-normalization transform after frozen embeddings. Sweep input cosine similarity and k. It should improve held-out discrimination mainly near the class boundary; an equal-parameter dense policy is the control. Reject the hypothesis if gains are uniform, vanish on disjoint paraphrases, or reflect changed scale alone. |
| [Baltruschat et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8741211/) | APL inhibition normalizes odor responses around KC dendrites/PN boutons, with regionalized reciprocal interactions. This argues against treating APL as a single exact global-normalization formula. | Compare global gain control, local/grouped gain control, and matched rescaling. Test robustness across feature norm and mixtures of two intents. A local scheme should preserve a weak diagnostic feature beside a strong distractor better than fixed global normalization. |
| [Hige et al., 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4674068/) | Pairing odor and identified dopamine-neuron activation produced odor-specific depression in a particular MB compartment, with a narrow ordering rule. This is evidence for compartmentalized heterosynaptic plasticity, not a universal timing constant. | Route feedback only to the action/value head that produced the committed action. Sweep outcome delay and cue/feedback order; compare routed, global, and shuffled-head updates. Predeclare the delay kernel and require an interaction between correct routing and timing. |
| [Aso & Rubin, 2016](https://elifesciences.org/articles/16135) | Activating individual dopamine-cell types produced memories with different acquisition, decay, capacity, and timing rules; the same cell type could write or reduce memory depending on order. Optogenetic sufficiency is not proof that all natural reinforcement uses the same rule. | Give separate plastic channels distinct, fixed learning/decay constants. Evaluate acquisition, reversal, and retention jointly. A single global learner is the comparator; shuffled channel assignment tests whether specialization, rather than added parameters, matters. |
| [Handler et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC9012144/) | In a fly odor-learning preparation, cue/reinforcement order drove bidirectional behavioral and KC–MBON plasticity; DopR1 and DopR2 pathways contributed differently. Receptor expression outside the MB limits a purely local interpretation. | Use signed, order-sensitive updates rather than treating any nearby reward as equivalent. Cross cue-before-outcome, cue-after-outcome, and matched unpaired controls. Reject the analogy if order effects occur without action-contingent feedback or are explained by recency. |
| [Felsenberg et al., 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5392358/) | Re-exposure to an appetitively conditioned odor without expected reward engaged distinct updating regimes depending on re-exposure conditions. Behavioral weakening therefore need not identify erasure. | After acquisition, vary reminder duration and context, then test retention, renewal, and reinstatement. Fit overwrite and dual-trace models on training data and compare preregistered held-out predictions. |
| [Felsenberg et al., 2018](https://doi.org/10.1016/j.cell.2018.08.021) | Aversive-memory extinction recruited reward circuitry and formed a parallel opposing memory whose integration altered behavior. The work concerns a defined olfactory paradigm, not every type of correction or forgetting. | Preserve the original value trace and learn a context-indexed opposing trace. Extinguish in context B; test B, original context A, delayed spontaneous recovery, and unsignaled outcome reinstatement. Suppressed performance in B alone cannot be called forgetting. |
| [Das et al., 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3169145/) | Repeated odor exposure induced olfactory habituation through plasticity of inhibitory local neurons in the antennal lobe. This is an early sensory-circuit mechanism, distinct from semantic interpretation. | Factor exact surface repetition, embedding similarity, and task meaning. A sensory adaptation module may attenuate identical repeated inputs, but should recover after a gap and should not define a semantically new request as familiar solely from vector proximity. |
| [Hattori et al., 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5806120/) | Repeated odor exposure suppressed responses in a specific α′3 MBON class through dopamine-dependent plasticity and reduced an alerting response. Other compartments showed different response changes, so this is not a global novelty scalar. | Keep sensory repetition and learned familiarity as separate logged variables. Compare exact repeats, paraphrases with the same intent, lexically similar requests with different intent, and novel distractors. A useful familiarity head should predict repeat history without replacing the policy’s semantic decision. |
| [Krashes et al., 2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC2780032/) | Hunger promoted expression of appetitive memory through dNPF and a small dopamine-neuron set; manipulations could release or suppress retrieval. The result supports state-dependent expression, not a generic utility optimizer. | Let trusted host state gate retrieval/action values while holding the cue constant. Cross hungry/sated state with reward availability; include absent-state and shuffled-state controls. FunctionGemma may request a goal, but must not invent the hidden state. |

Suvrathan et al. (2016) is intentionally excluded from the fly evidence set: it studied timing rules at mammalian cerebellar Purkinje-cell synapses, not the Drosophila mushroom body. It is at most a comparative warning that timing constants can be circuit and task specific. Likewise, dopamine-dependent plasticity in the fly heading system can reflect movement and head-direction dynamics rather than reward; dopamine must not be labeled a reward signal solely because it gates plasticity ([Fisher et al., 2022](https://www.nature.com/articles/s41586-022-05485-4)).

## Five preregisterable experiments

### 1. Sparse separation under controlled semantic overlap

Construct disjoint train/validation/test utterances for fixed needs, plus Korean transfer. Before labels are exposed, bin test pairs by frozen-embedding cosine similarity. Compare a linear policy on raw features with the same policy after fixed top-k competition, global normalization, or grouped normalization. Keep parameter counts, optimizer steps, and seeds matched. Primary outcome: accuracy as a function of between-class similarity; secondary outcomes: within-class generalization and calibration. This tests an engineered pattern-separation hypothesis, not whether language features behave like odors.

### 2. Delayed credit with routed plasticity

The host logs cue ID, validated action, timestamp, and output head in a bounded queue. Feedback is issued only after an environment transition, with delay and order randomized independently of class. Compare no eligibility, exponential eligibility, a rectangular window, shuffled timestamps, and outcome-before-action controls. Cross global updates with action-head routing. Report the complete delay curve rather than selecting the best delay after inspection. The queue is an audit-ready software device; no observation of molecular or synaptic eligibility follows from success.

### 3. Retrieval, extinction, and erasure challenge

Train cue-to-action associations in context A. In context B, repeatedly omit the expected outcome or reverse it. Test immediately and after delay in both contexts, then deliver an unsignaled outcome and retest. An overwrite model predicts broad loss; a context-gated opposing trace predicts renewal or reinstatement of the first association. Weight probes must accompany behavior, because non-expression is insufficient evidence of deletion.

### 4. Adaptation versus semantic novelty

Use a factorial sequence: exact repeated string, paraphrase of the same request, lexically close different request, and unrelated request. Cross these with short versus long interstimulus intervals. Measure (a) preprocessing gain, (b) frozen vector, (c) familiarity estimate, (d) chosen action, and (e) latency. Sensory adaptation should be repetition- and time-dependent; semantic novelty is defined by task consequences and cannot be inferred from embedding distance alone. Compare an early adaptation module, a learned familiarity head, both, and neither.

### 5. State-gated retrieval and grounded reward

Hold language constant while the host varies water, food, warmth, and rest deficits. The environment computes reward from the post-action state transition, resource cost, and safety constraints; FunctionGemma never supplies the reward. Compare state-gated values, state concatenation, no state, and shuffled state. Include conflicts in which the stated request disagrees with the measured deficit. Success requires better cumulative physically grounded reward without increased invalid or unsafe actions, plus correct behavior when a state field is missing. This tests whether state improves selection; it does not establish a fly-like motivational circuit.

## Interface and inference safeguards

- Split data by paraphrase family and scenario template before training; keep translations and near duplicates in one split.
- Validate FunctionGemma tool schemas, allowed ordering, and state preconditions before any mutation. A syntactically valid symbol is only a proposal.
- Keep hidden state and reward environment-only. Text that says “I am hungry” is an observation whose reliability must be modeled, not privileged ground truth.
- Log ablations and all seeds. Avoid counting many trials from one learned policy as independent biological-style replicates; summarize both seed-level and trial-level uncertainty.
- Do not infer erasure from low choice probability, novelty from vector distance, eligibility from a queue, compartment identity from a software head, or neural homology from functional resemblance.
