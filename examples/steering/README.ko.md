# Hugging Face 데이터로 조향 흉내 내기

측정 결과는 시험 정확도 **60%**, 항상 직진하는 기준선 **58%**입니다. 좌·우 예측은 부족합니다. [전체 결과](../../results/STEERING_REPORT.ko.md)에 한계와 대조군을 기록했습니다.

전방 카메라 영상을 보고 좌회전·중립·우회전 명령을 예측하는 작은 모방학습 예제입니다. 기존 FlyWire 기반 희소 엔진, 이미지 입력 어댑터, Safetensors 저장·추론 경로를 그대로 사용합니다. 실제 자율주행 시스템 구현이 목표는 아닙니다.

데이터는 [URJC DeepRacer CARLA expert racing](https://huggingface.co/datasets/urjc-deepracer/carla-expert-racing)의 시뮬레이터 영상과 전문가 조향입니다. 게시자의 라이선스 표기는 Apache-2.0이며, Novigrad 소스의 MIT 라이선스와 별도로 적용됩니다.

입력은 카메라 픽셀뿐입니다. 조향 값은 정답으로만 사용하고 maneuver, 정답 분할 마스크, 세션 ID, 시간은 모델에 넣지 않습니다. 속도는 원본에 큰 이상치가 있어 제외합니다. 이미지 어댑터는 학습 영상만으로 맞추며, 서로 다른 주행 세션으로 검증합니다. 연속 프레임을 띄워 추출해도 남은 표본들이 완전히 독립적이지는 않습니다.

정규화된 조향 값 -0.2와 +0.2를 경계로 세 종류의 명령을 만듭니다. 각 종류의 학습 데이터 평균 조향 값을 예측 확률로 가중하면 거친 연속 조향 값도 얻을 수 있습니다. 이는 세 구간 분류기의 디코딩이며, 연속 제어 모델은 아닙니다.

보지 못한 세션의 기록된 조향을 얼마나 따라 하는지만 측정합니다. 충돌 회피, 실수 뒤 복구, 실제 차선 유지 성능은 검증하지 않습니다. 향후 필요하면 `Runtime`의 관측→행동 루프를 시뮬레이터에 연결하고 진행 거리·충돌 등에 지연 보상을 줄 수 있습니다.

실행 명령과 측정 결과는 [영문 예제](README.md)에 함께 기록합니다.

## 30 FPS 주기 재생

`novi_api`에 모델을 올린 뒤 `scripts/replay_steering.py`로 저장된 JPEG를 주기적으로 입력할 수 있습니다. 어댑터와 HTTP 연결을 재사용하고, 늦어진 주기는 쌓지 않고 건너뜁니다. 매 프레임의 예측·확률·지연시간·주기 초과를 CSV로 남깁니다.

M2 Ultra에서 30 FPS·300회 실행 결과: **평균 2.77ms, p95 3.21ms, p99 3.38ms, 최대 3.48ms**, 33.33ms deadline 초과와 건너뛴 슬롯은 모두 0회였습니다. JPEG 읽기·변환·어댑터·HTTP 추론·조향 디코딩을 포함합니다. 초기 로딩, 준비 실행 10회, 대기 시간, 최종 파일 쓰기는 제외합니다.

현재 측정에서는 속도에 여유가 있으며 조향 예측 품질이 더 큰 과제입니다. 저장된 50장을 반복 재생했으므로 실제 카메라의 노출·버퍼링·전송 지연, 액추에이터, 폐루프 제어는 포함하지 않습니다. 자세한 실행 명령은 [영문 예제](README.md#paced-replay-at-30-fps), 측정치는 [원시 결과](../../results/steering/realtime30/summary.json)에 있습니다.
