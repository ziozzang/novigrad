# Delayed reward modulation and odor-to-action example

The adult fly mushroom body is a useful biological reference for odor learning: Kenyon cells carry sparse odor information; dopaminergic neurons (DANs) convey reinforcing signals to compartments; coincidence with Kenyon-cell activity changes KC→MBON connections. Some MBONs influence locomotor pathways through the central complex or descending steering system. These facts are described in the [adult mushroom-body connectome study](https://elifesciences.org/articles/62576) and a [reward-prediction circuit model](https://elifesciences.org/articles/75611). The FlyWire dataset is a [whole adult female **brain** connectome](https://www.nature.com/articles/s41586-024-07558-y); brain and ventral nerve cord (VNC) are physically separate connectome datasets, and matching descending neurons between them is an active research task ([comparative study](https://www.nature.com/articles/s41586-025-08925-z)).

The local `neurons_783.tsv` annotations contain 331 `DAN`, 96 `MBON`, and 1,303 `descending` rows, but no `motor` cell-class rows. These counts are from this file's annotation fields, not a full CNS inventory. In particular, the current PN→KC→MBON example does **not** contain a reconstructed MBON→foreleg motor-neuron path. Its two output actions are external virtual commands, such as “move left foreleg” and “move right foreleg,” decoded from MBON rates; they are not neuron IDs or demonstrated motor control.

`novi::modulation::DelayedReward` adds an engineered delayed-feedback layer around the existing topology-defined `Engine`. It preallocates a bounded ring of input-rate vectors and chosen actions. `observe()` computes a policy without changing weights, then `record_action()` stores the action. During an episode, the controller owns the engine and leaves all synaptic weights fixed. At `signal(reward)`, it computes a scalar reward-prediction error `reward − baseline`, re-forwards each stored input at the same weights, scales older events by `lambda^age`, averages the resulting reward gradients, and applies one sign-constrained update. The baseline then moves toward the reward by `baseline_alpha × error`. It clears the trace. This is eligibility **replay** and an engineered scalar baseline, not measured dopamine release, DAN compartment dynamics, biological eligibility traces, or an anatomical motor circuit.

The API rejects invalid or over-capacity observations, unpaired actions, and reward outside `[-1,1]`; it will not save a checkpoint while an episode is open. `discard_episode()` clears the trace without learning. A zero reward still produces a negative prediction error when the learned baseline is positive. The ordinary Safetensors model schema remains unchanged, so `Engine::load_checkpoint()` can load an example's saved weights. The controller's transient trace and scalar baseline are not persisted.

```sh
cargo build --release --bin odor_motor
./target/release/odor_motor --episodes 300 --seed 1 --mode reward --reverse-after 300 --out /tmp/odor-reward.safetensors
./target/release/odor_motor --episodes 300 --seed 1 --mode shuffled --reverse-after 300 --out /tmp/odor-shuffled.safetensors
./target/release/odor_motor --episodes 600 --seed 1 --mode reward --reverse-after 300 --out /tmp/odor-reversal.safetensors
```

The example uses 32 real ALPN input IDs from the local FlyWire-derived PN→KC edge file, randomized sparse rates in two synthetic odor groups, the real 27,848 fixed PN→KC and 62,261 plastic KC→MBON edges, and two **virtual** actions. Each reward arrives after three observations. `reward` uses the correct odor-action mapping, `shuffled` draws an action-independent reward target, and `frozen` discards each episode without updates. `--reverse-after` flips the correct action after that episode; set it equal to `--episodes` for no reversal.

In one bounded run of 300 episodes with eight seeds, reward-trained models scored **100%** on 400 fresh synthetic odor draws per seed; the shuffled-reward control averaged **46.09%** (range 9–82.25%), and the frozen policy scored **33%**. With reversal at episode 300 and 600 total episodes, seeds 1–3 each scored 100% on the original mapping before reversal and 100% on the reversed mapping afterward. The shuffled variation is large because this tiny two-class task has few effective input patterns and online stochastic actions. These measurements establish delayed reward learning in the same engine on this narrow synthetic task; they do not establish physical foreleg control, general olfaction, or biological dopamine fidelity.
